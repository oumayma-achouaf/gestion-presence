# 🧑‍💼 HR Management System (Laravel)

## 📌 Description
This project is a web-based **Human Resource Management System** developed using the Laravel framework.  
It allows the management of employees, attendance, absences, and schedules in an organized and efficient way.

The system was designed to simplify HR operations and improve data management within an organization.

---

## 🎯 Main Features

- 👨‍💼 Employee Management (Add / Edit / Delete / View)
- 📅 Absence Management
- 🕒 Attendance Tracking
- 👤 User Authentication (Login / Logout)
- 📊 Dashboard with statistics
- 📆 Schedule / Planning management

---

## 🛠️ Technologies Used

- Laravel (PHP Framework)
- MySQL (Database)
- HTML5 / CSS3
- Bootstrap (Responsive UI)
- JavaScript
- XAMPP (Local Development Environment)

---

## 🏗️ Project Architecture

The application follows the **MVC (Model - View - Controller)** architecture:

- **Model:** Handles database logic
- **View:** Blade templates (UI)
- **Controller:** Business logic and requests handling

---

## 📂 Database Structure

Main tables used in the system:

- users
- employees
- absences
- attendances
- schedules

Relationships:
- One employee can have multiple absences
- One employee can have multiple attendances
